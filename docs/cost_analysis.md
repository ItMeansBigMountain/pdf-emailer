
# 3. 📊 Cost Analysis

## Key Cost Drivers

| Service | Pricing |
|:--------|:--------|
| Azure Function Executions | Free for 1M calls/month, then ~$0.20/million |
| OpenAI API (GPT-3.5-turbo) | ~$0.002–0.004 per request |
| SMTP Email (Gmail) | Free under 500/day |
| Azure Storage | Minimal ($0.01/GB)


## Estimated Monthly Costs

| Volume | Est. Monthly Cost |
|:------|:-----------------|
| 1,000 newsletters | ~$2–4 |
| 10,000 newsletters | ~$20–40 |


> Costs are extremely low for small/medium usage. Biggest expense: large token prompts in LLM usage.
